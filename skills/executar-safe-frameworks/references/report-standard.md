# Standard Report Contract

## Contents
- Required metadata
- Required sections
- Framework card
- Cross-framework synthesis
- Mobile-first rules

## Required metadata
`REPORT_ID`, `DATE`, `OBJECT`, `INTENT`, `MODE`, `SCOPE`, `FRAMEWORK_SET`, `EVIDENCE_STATUS`.

## Required sections
1. Executive synthesis
2. Object and intent
3. Evidence base
4. Framework selection and technical justification
5. Framework analyses
6. Cross-framework synthesis
7. Gaps, conflicts and limitations
8. Decision implications or next research
9. Sources

## Framework card
Each framework card contains: ID/name; question answered; why selected; inputs/evidence; structured analysis; interpretation; limitations; confidence when useful.

## Cross-framework synthesis
Separate: convergences, tensions, dependencies, unresolved questions and implications. Avoid repeating all framework content.

## Mobile-first rules
Prefer short sections, compact tables, 3–7 bullets per block and one idea per bullet. Avoid wide tables with more than 4 essential columns. Put detailed evidence in a ledger or appendix when it would disrupt reading.
