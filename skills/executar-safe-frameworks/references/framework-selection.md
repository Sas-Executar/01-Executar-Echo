## Selection objective
Choose the smallest non-redundant set of frameworks that answers the user's real question with the evidence actually available.

## Lens model
Potential lenses: external environment; industry/competition; internal capabilities; customer/job; market size/segments; product/fit; business model/economics; risk/compliance; process/operations; execution/prioritization; experience/design; engineering/architecture; research/evidence; sales/growth; decision/governance.

## Scoring questions
For each candidate ask:
1. Decision fit — does it answer a question the user actually has?
2. Evidence fit — can its fields be populated with available or obtainable evidence?
3. Complementarity — does it add a distinct lens?
4. Actionability — will it change understanding, options or next research?
5. Cognitive compression — does it reduce complexity rather than add ceremony?
6. Misuse risk — could the framework create false precision or oversimplification here?

## Composition rules
- Default: 2–5 frameworks.
- Do not pair SWOT and TOWS unless both diagnosis and strategy conversion are needed.
- Do not pair BCG and GE–McKinsey by default; choose based on portfolio question and data quality.
- Use PESTEL for macro-environment, not firm capability.
- Use Five Forces for industry structure, not internal performance.
- Use PMF only when evidence about actual customer behavior/value exists; otherwise prefer Problem-Solution Fit or assumption testing.
- Use TAM/SAM/SOM only when market scope and sizing assumptions are explicit.
- Use FMEA when failure modes can be meaningfully enumerated; use risk matrix for broader risk triage.

## Common bundles
These are starting points, not mandatory recipes:
- Market/business: PESTEL + Five Forces + SWOT/TOWS + TAM/SAM/SOM.
- Product fit: JTBD + Value Proposition Canvas + PMF + retention/cohort evidence.
- New product discovery: Problem-Solution Fit + Opportunity Solution Tree + Assumption Mapping + RAT.
- Operations: SIPOC + Value Stream Mapping + Theory of Constraints + FMEA.
- Finance/business viability: Unit Economics + Break-even + Sensitivity Analysis + TCO.
- Customer experience: Journey Map + VoC + CES/CSAT/NPS as appropriate.
- Research quality: FINER + Evidence Matrix + Triangulation; systematic review only when scope warrants it.
- Engineering: C4 + ADR + Threat Modeling + Requirement Traceability when architecture and verification matter.
- Decision: Decision Matrix + Scenario Planning + Pre-mortem.

## Misuse controls
A framework may be rejected even if popular. Document the reason when it lacks evidence, duplicates another lens, is outside scope, requires unavailable data, or would encourage unsupported precision.
