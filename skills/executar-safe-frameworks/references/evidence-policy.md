# Evidence and Citation Policy

## Contents
- Evidence classes

## Evidence classes
- P0: authoritative primary evidence — official statistics, regulator, law/standard, filing, first-party system record.
- P1: strong independent evidence — peer-reviewed research, systematic review, recognized institution.
- P2: reputable secondary evidence — established analysis/reporting with transparent sourcing.
- P3: contextual evidence — expert commentary, community reports, anecdotal material.

Source class is not a guarantee of truth. Check applicability, date and scope.

## Claim states
- FACT: directly supported by evidence.
- INFERENCE: reasoned interpretation from facts; identify supporting facts.
- HYPOTHESIS: plausible but not yet sufficiently verified.
- CONFLICT: credible evidence disagrees.
- EVIDENCE_GAP: required information is absent.

## Confidence
Use High / Medium / Low only when useful. Confidence must reflect evidence quality, consistency and applicability—not the number of frameworks repeating the same source.

## User documents
Treat user documents as primary evidence for the user's internal facts. Preserve page, section, sheet, cell, line or record location when available. Do not “correct” internal facts with web sources unless the external evidence directly contradicts them; instead record the conflict.

## Web evidence
Cite sources close to the claims they support. For current or consequential claims, prefer applicable primary evidence. Search results are discovery aids; the underlying source is the evidence.
