- QG-02 Evidence

## QG-01 Intent
PASS when object, question and analytical purpose are explicit.

## QG-02 Evidence
PASS when material claims are sourced or clearly labeled inference/hypothesis/gap; current claims use sufficiently current evidence.

## QG-03 Framework fit
PASS when each selected framework answers a distinct necessary question and has enough evidence to be useful.

## QG-04 Traceability
PASS when framework conclusions can be traced to user inputs or external sources and conflicts are visible.

## QG-05 Synthesis
PASS when cross-framework conclusions distinguish convergence, tension and uncertainty instead of merely concatenating outputs.

## QG-06 Output
PASS when report follows the standard schema, remains readable, does not fabricate missing fields and states limitations.

DONE requires all gates PASS or explicit disclosure of any failed gate and its impact.
