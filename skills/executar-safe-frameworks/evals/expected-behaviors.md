# Expected Behaviors

The Skill passes behavioral evaluation when it reliably: triggers for framework-based research and document conversion; infers intent before selecting tools; chooses a small complementary set; justifies selection; uses current sources for volatile facts; preserves user-document provenance; labels inference and gaps; surfaces conflicts; and produces the standard report instead of a framework dump.

Failure examples: inventing SWOT cells; estimating TAM without assumptions; calling PMF on a pre-user concept as if validated; treating framework output as evidence; using a search snippet as final proof; or selecting five frameworks that answer essentially the same question.
