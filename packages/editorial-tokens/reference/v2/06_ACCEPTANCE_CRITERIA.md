# 06 — Critérios de Aceite v2

## Identidade única
- [ ] Existe somente `EXECUTAR Native Editorial`.
- [ ] Não há tema azul, Notes, Reader ou outra variante paralela.
- [ ] Nenhum componente usa paleta própria.

## Apple alignment
- [ ] Conteúdo é visualmente dominante.
- [ ] Accent de marca é parcimonioso.
- [ ] System font stack é padrão.
- [ ] Chrome e conteúdo são visualmente separados por função.
- [ ] Glass, quando usado, está restrito ao chrome.
- [ ] Padrões de navegação são familiares e previsíveis.
- [ ] Dark mode deriva de papéis semânticos.

## Editorial
- [ ] artigo <=760px e ~66ch;
- [ ] body >=17px;
- [ ] line-height 1.6;
- [ ] uma única coluna dominante;
- [ ] TOC não compete com leitura;
- [ ] CTA aparece após contexto/valor.

## Acessibilidade
- [ ] target >=44px;
- [ ] focus-visible;
- [ ] contraste AA no mínimo;
- [ ] reduced motion;
- [ ] labels programáticos;
- [ ] reflow sem perda;
- [ ] zoom de texto sem truncamento crítico.

## Performance
- [ ] LCP <=2.5s;
- [ ] INP <=200ms;
- [ ] CLS <=0.1.

## DONE
`DONE` exige build implementada + QA visual + acessibilidade + evidências.
