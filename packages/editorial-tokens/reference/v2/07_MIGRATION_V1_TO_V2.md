# 07 — Migração v1 → v2

## Remover
- azul como cor de identidade;
- cards com sombra decorativa;
- múltiplas famílias editoriais;
- gradients;
- glass em conteúdo;
- tokens genéricos aplicados diretamente.

## Preservar
- arquitetura mobile-first;
- home em 6 zonas;
- página de artigo orientada à leitura;
- sumário contextual;
- evidências;
- CTA contextual;
- newsletter;
- footer;
- metas de Core Web Vitals.

## Alterar
| v1 | v2 |
|---|---|
| paleta genérica | papéis semânticos adaptativos |
| accent amplo | accent restrito |
| sombra em cards | espaço/contraste tipográfico |
| “Apple-like” implícito | regras explícitas de HIG alignment |
| possíveis variantes | uma identidade canônica |
| 68ch | 66ch |
| 18px fixo | 17px base + adaptação |
| glass opcional | glass somente no chrome |

## Resultado
A migração é principalmente de linguagem visual, não de arquitetura de informação.
