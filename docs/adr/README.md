# Architecture Decision Records — ratified

This directory holds **ratified** ADRs for `Sas-Executar/01-Executar-Echo`.
It is distinct from `docs/executar/ADRS_CANDIDATOS/`, which holds proposals
that have not been accepted.

Prior decisions are never deleted. When a decision stops applying, it is
marked `SUPERSEDED` (wholly) or `SUPERSEDED_IN_PART` (scoped down), with a
pointer to the record that replaced it — so the reasoning behind the
earlier choice stays readable.
